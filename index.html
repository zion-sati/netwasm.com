Choose the collector for your workload

Compact is the size-first default. NetWasmGC favors throughput; Bump never collects. In 0.10.0 objects carry no collector header, so Compact and NetWasmGC use far less memory. All use the same SDK selection setting.

Call C# from JavaScript.
Like any other module.

A JsModule project publishes C# [JSExport] methods as a typed JavaScript module. A page imports it, calls open(), and calls the exports directly: synchronously on the page, or behind Promises in a Web Worker. C# calls back into JavaScript, including the DOM, through [JSImport].

.mjs

A typed module for your page

Publish writes the module and its .d.mts declarations, named after your C# parameters and nullability. Exports take and return strings, typed arrays, and JSObject.

Local quickstart

Try the real thing.

Install .NET SDK 10.0.303 or newer, create an app, run it locally, and publish a standalone component. Use the .NET 11 SDK when your source uses C# 15.

Five supported development hosts: Linux x64, Linux ARM64, macOS ARM64, Windows x64, and Windows ARM64. NuGet downloads the pinned host tools on first restore and reuses them on later builds. No separate Emscripten, Node.js, Python, Git, LLVM, or Binaryen setup is needed.
