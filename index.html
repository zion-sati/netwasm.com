Measured size

Less than half Rust's size.
With precise GC included.

The released SDK produces a 27,583-byte Release/Oz component for Console.WriteLine(42), or 11,525 bytes with Brotli quality 11. Rust 1.100.0's documented size-oriented profile produces a 63,528-byte WASI 0.3 component for the same print-42 workload. Running wasm-opt by hand on the core module of Rust's WASI 0.2 build, then re-encoding and stripping the component, brings it to 41,185 bytes: still larger. This is a measured workload, not a claim about the smallest possible Rust binary.

The qualified Console.WriteLine(42) Release component includes the application, runtime, Compact GC, and WASI component wrapper.

Generational collection

Keep a big heap.
Collect only what's new.

NetWasmGen is NetWasmGC with generations. Most of its collections look only at the objects allocated since the last one and at the old objects the program stored a reference into, so a program that keeps a large set of objects alive while short-lived ones come and go spends far less time collecting. Choose it for services over in-memory state, per-frame garbage, and building and discarding trees.

Like any other module.

A JsModule project publishes C# [JSExport] methods as a typed JavaScript module. A page imports it, calls open(), and calls the exports directly: synchronously on the page, or behind Promises in a Web Worker. C# calls back into JavaScript, including the DOM, through [JSImport].

Publish writes the module and its .d.mts declarations, named after your C# parameters and nullability. Exports take and return strings, typed arrays, and JSObject.

Local quickstart

Try the real thing.

Install .NET SDK 10.0.303 or newer, create an app, run it locally, and publish a standalone component. Use the .NET 11 SDK when your source uses C# 15.

Five supported development hosts: Linux x64, Linux ARM64, macOS ARM64, Windows x64, and Windows ARM64. NuGet downloads the pinned host tools, including the native nwc compiler, on first restore and reuses them on later builds. No separate Emscripten, Node.js, Python, Git, LLVM, or Binaryen setup is needed.
