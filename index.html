Local quickstart

Try the real thing.

Install the build prerequisites first, then create an app, run it locally, and publish a standalone Component.

Required: .NET SDK 10.0.300+, Git, Python 3, and Emscripten SDK 6.0.7. Activate Emscripten in every new shell; it supplies the Node.js 24+ and LLD 24+ host tools NetWasm uses.

Read the full quickstart ↗
terminal 
$ source ~/emsdk/emsdk_env.sh
$ dotnet new install NetWasm.Templates
$ dotnet new netwasm-app -n HelloNetWasm
$ cd HelloNetWasm
$ dotnet run
42
$ dotnet publish -c Release -o publish/local
