# netwasm.com

Source for the NetWasm product site at [www.netwasm.com](https://www.netwasm.com/).

The homepage introduces NetWasm as a C# to WebAssembly compiler. The
[`compile-csharp-to-webassembly`](compile-csharp-to-webassembly/) guide provides
the durable category page and end-to-end quickstart used by search engines and
developers evaluating the toolchain.

The site is static and has no build step. Serve this directory with any local
HTTP server, for example:

```sh
python3 -m http.server 8080
```
